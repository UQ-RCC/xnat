Use an [alias token](/user-guides/processing-data/alias-tokens) to connect an external tool to XNAT. Choose the client that suits your workflow.

## Choose a tool

<Tabs>
<TabItem label="xnatutils">

### Install

Install [xnatutils](https://github.com/Australian-Imaging-Service/xnatutils) from PyPI:

```bash
pip3 install xnatutils
```

### Authenticate with an alias token

Create a `.netrc` file in your home directory and add your XNAT server, alias and secret:

```text
machine https://xnat.rcc.uq.edu.au
user <your-alias>
password <your-alias-secret>
```

</TabItem>
<TabItem label="xnatpy">

### Install

Install [xnatpy](https://xnat.readthedocs.io/en/latest/) from PyPI. The package name is `xnat`:

```bash
pip install xnat
```

### Authenticate with an alias token

Pass your alias and secret when you create a session:

```python
import xnat

with xnat.connect(
    'https://xnat.rcc.uq.edu.au',
    user='<your-alias>',
    password='<your-alias-secret>',
) as session:
    print(session.projects)
```

</TabItem>
<TabItem label="pyxnat">

### Install

Install [pyxnat](https://pyxnat.github.io/pyxnat/) from PyPI:

```bash
pip install pyxnat
```

### Authenticate with an alias token

Pass your alias and secret when you create an interface:

```python
from pyxnat import Interface

xnat = Interface(
    server='https://xnat.rcc.uq.edu.au',
    user='<your-alias>',
    password='<your-alias-secret>',
)
print(xnat.select.projects().get())
```

</TabItem>
</Tabs>

## Protect your credentials

Do not commit an alias or secret to source control. Restrict access to a `.netrc` file on Linux or macOS:

```bash
chmod 600 ~/.netrc
```

Revoke the alias token in XNAT when you no longer need it or if its secret may have been exposed.
