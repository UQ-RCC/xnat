You can start a Jupyter notebook server directly from XNAT and analyse your
project data without downloading it. The environment is built on
[Neurodesk](https://neurodesk.org/getting-started/hosted/xnat/), which provides a
large suite of containerised neuroimaging tools alongside the usual Python and
Jupyter stack.

RCC support sets up access on request.

## Request access to the Jupyter environment

<Steps>

1. Open a ticket with RCC support. Fill in the XNAT projects that should be accessible from the Jupyter environment, then copy the generated email into your mail client.

   <RequestEmailForm
     fields={[{ id: 'projects', label: 'XNAT Projects', placeholder: 'e.g. Q1111, Q2222' }]}
     subject="Request Jupyter environment access to XNAT project data for {projects}"
     body={"Hello RCC support,\n\nCould you please enable Jupyter environment access to XNAT project data for {projects}?\n\nThank you"}
   />

2. The support ticket will inform you when your access is set up. Jupyter access setup typically takes around ~24 hours from ticket submission.

</Steps>

## Start an interactive session

<Steps>

1. Open the project you want to work with.

   ![Select a project](./select-project.png)

2. Select **Start Jupyter Notebook** from the **Actions** menu.

   ![Start Jupyter action](./actions-start-jupyter.png)

3. Choose a **Jupyter Environment** and **Hardware**, then select **Start Notebook**.

   The environment determines which software is available. `neurodesk-latest`
   gives you the [Neurodesk](https://www.neurodesk.org) toolset. The hardware
   option sets the memory and CPU available to the server, so pick a size that
   matches the analysis you are running.

   ![Jupyter settings](./start-jupyter.png)

4. Open the Jupyter window once the server has started.

   ![Open Jupyter window](./open-jupyter.png)

</Steps>

## Using interactive session

The project data will be accessible as read-only at:
```
/data/projects
```
