If your organisation is not an AAF member, QCIF and QRIScloud can provide an AAF
Virtual Home (VHO) account so you can log in. Request that first.

## Request an AAF VHO account

<Steps>

1. Open a ticket with RCC support. Fill in your details below, then copy the
   generated email into your mail client.

   <RequestEmailForm
     fields={[
       { id: 'project', label: 'XNAT Project Name', placeholder: 'e.g. MyProject' },
       { id: 'org', label: 'Organisation', placeholder: 'e.g. QLD Health' },
       { id: 'site', label: 'Data Acquisition Site', placeholder: 'e.g. HIRF, CAI, TRI' },
     ]}
     subject="XNAT AAF account for project {project}"
     body={"Hello RCC support,\n\nI require an AAF account to access the UQ XNAT service.\n\nMy details are below:\nOrganisation: {org}\nData Acquisition Site: {site}\n\nThank you"}
   />

2. AAF's VHO service will email you about the account registration process.

</Steps>

## Logging into XNAT

<Steps>

1. Open [https://xnat.rcc.uq.edu.au](https://xnat.rcc.uq.edu.au) and log in with
   the AAF Single sign-on button.

   ![XNAT AAF login page](../logging-into-xnat/xnat-aaf-login-page.png)

2. Select the **AAF Virtual Home** option and log in with your VHO credentials.

   ![AAF Virtual Home login](../logging-into-xnat/aaf-virtual-home-login.png)

   ![AAF VHO sign-in](../logging-into-xnat/aaf-vho-signin.png)

3. After the AAF sign-in you are redirected back to XNAT. There will be **no
   projects listed** the first time.

   ![Signed in to XNAT](./xnat-signed-in.png)

</Steps>
